# 4.22
Show that a finitely generated free module $F$ has finite rank.

**Proof**

Let $F$ be a finitely generated free module, and let $`\{f_1, \ldots, f_n\}`$ be a finite generating set for $F$. Since $F$ is free, there exists a basis $`\{e_i\}_{i \in I}`$ for $F$. Each generator $f_j$ can be expressed as a linear combination of the basis elements:

$f_j = \sum_{i \in I} r_{ij} e_i,$

where $r_{ij} \in R$ and only finitely many $r_{ij}$ are nonzero for each $j$. Since there are only finitely many $j$, the set $`\{e_i \mid r_{ij} \neq 0 \text{ for some } j\}`$ is finite. Let $`I' = \{i \in I \mid r_{ij} \neq 0 \text{ for some } j\}`$. Then $`\{e_i\}_{i \in I'}`$ is a finite subset of the basis that generates $F$. Since the basis $I$ is minimal and $I'\subseteq I$, it follows that $I' = I$ is finite, and thus $F$ has finite rank equal to the cardinality of $I'$.

# 4.26
Let $L, M$, and $N$ be modules. Consider a diagram

$L \xtofrom[\rho]{\alpha} M \xtofrom[\sigma]{\beta}N$

where $\alpha, \beta, \rho$, and $\sigma$ are homomorphisms. Prove that

$M=L \oplus N \quad \text { and } \quad \alpha=\iota_L, \beta=\pi_N, \sigma=\iota_N, \rho=\pi_L$

if and only if the following relations hold:

$\beta \alpha=0, \beta \sigma=1, \rho \sigma=0, \rho \alpha = 1, \text { and } \alpha \rho+\sigma \beta=1 .$

**Proof**

- Direction from Direct Sum to Relations

    Assume that $M = L \oplus N$ and that $\alpha(l) = (l, 0)$ for $l \in L$, $\beta(l, n) = n$ for $(l, n) \in L \oplus N$, $\sigma(n) = (0, n)$ for $n \in N$, and $\rho(l, n) = l$ for $(l, n) \in L \oplus N$. We will verify the relations:

    1. $\beta \alpha(l) = \beta(l, 0) = 0$ for all $l \in L$, so $\beta \alpha = 0$.
    2. $\beta \sigma(n) = \beta(0, n) = n$ for all $n \in N$, so $\beta \sigma = 1$.
    3. $\rho \sigma(n) = \rho(0, n) = 0$ for all $n \in N$, so $\rho \sigma = 0$.
    4. $\rho \alpha(l) = \rho(l, 0) = l$ for all $l \in L$, so $\rho \alpha = 1$.
    5. $\alpha \rho(l, n) + \sigma \beta(l, n) = \alpha(l) + \sigma(n) = (l, 0) + (0, n) = (l, n)$ for all $(l, n) \in L \oplus N$, so $\alpha \rho + \sigma \beta = 1$.
- Direction from Relations to Direct Sum

    Define the isomorphism $\phi: L \oplus N \rightarrow M$ by $\phi(l, n) = \alpha(l) + \sigma(n)$ for $l \in L$ and $n \in N$. We will show that $\phi$ is an isomorphism.

    - **Injectivity**: Suppose $\phi(l, n) = 0$. Then $\alpha(l) + \sigma(n) = 0$. Applying $\beta$ to both sides gives $\beta \alpha(l) + \beta \sigma(n) = 0$, which simplifies to $0 + n = 0$, so $n = 0$. Applying $\rho$ to both sides gives $\rho \alpha(l) + \rho \sigma(n) = 0$, which simplifies to $l + 0 = 0$, so $l = 0$. Thus, $(l, n) = (0, 0)$, and $\phi$ is injective.
    - **Surjectivity**: Take any $m \in M$. We can write $m = \alpha(\rho(m)) + \sigma(\beta(m))$ using the relation $\alpha \rho + \sigma \beta = 1$. Thus, $m$ is in the image of $\phi$, and $\phi$ is surjective.

    Therefore, $\phi$ is an isomorphism.

# 4.27
Let $L$ be a module, $\Lambda$ a nonempty set, $M_\lambda$ a module for $\lambda \in \Lambda$. Prove that the injections $\iota_\kappa: M_\kappa \rightarrow \bigoplus M_\lambda$ induce an injection

$\bigoplus \mathrm{Hom}\left(L, M_\lambda\right) \hookrightarrow \mathrm{Hom}\left(L, \bigoplus M_\lambda\right),$

and that it is an isomorphism if $L$ is finitely generated.

**Proof**

Define the map $\Phi: \bigoplus \mathrm{Hom}(L, M_\lambda) \rightarrow \mathrm{Hom}(L, \bigoplus M_\lambda)$ by $`\Phi((f_\lambda)_{\lambda \in \Lambda})(l) = (f_\lambda(l))_{\lambda \in \Lambda}`$ for $l \in L$. We will show that $\Phi$ is an injection and that it is surjective if $L$ is finitely generated.

- **Injectivity**: Composing $\Phi$ with the projection maps $\pi_\kappa: \bigoplus M_\lambda \rightarrow M_\kappa$ gives $`\pi_\kappa \circ \Phi((f_\lambda)_{\lambda \in \Lambda}) = f_\kappa`$ for each $\kappa \in \Lambda$. If $`\Phi((f_\lambda)_{\lambda \in \Lambda}) = 0`$, then $f_\kappa = 0$ for all $\kappa$, so $`(f_\lambda)_{\lambda \in \Lambda} = 0`$. Thus, $\Phi$ is injective.
- **Surjectivity**: Let $g \in \mathrm{Hom}(L, \bigoplus M_\lambda)$. Since $L$ is finitely generated, there exists a finite generating set $`\{l_1, \ldots, l_n\}`$ for $L$. For each $\lambda \in \Lambda$, define $f_\lambda: L \rightarrow M_\lambda$ by $f_\lambda(l_i) = \pi_\lambda(g(l_i))$ for $i = 1, \ldots, n$, and extend to all of $L$ by linearity. We must show that $`(f_\lambda)_{\lambda \in \Lambda} \in \bigoplus \mathrm{Hom}(L, M_\lambda)`$. For each generator $l_i$, $g(l_i) \in \bigoplus M_\lambda$, so the set $`\Lambda_i = \{\lambda \in \Lambda \mid \pi_\lambda(g(l_i)) \neq 0\}`$ is finite. Let $\Lambda' = \bigcup_{i=1}^n \Lambda_i$; this is a finite set. For $\lambda \notin \Lambda'$, we have $`f_\lambda(l_i) = \pi_\lambda(g(l_i)) = 0`$ for all $i$. Since the $l_i$ generate $L$, this implies $f_\lambda$ is the zero homomorphism. Thus, only finitely many $f_\lambda$ are non-zero, so $`(f_\lambda)_{\lambda \in \Lambda} \in \bigoplus \mathrm{Hom}(L, M_\lambda)`$. Then $`\Phi((f_\lambda)_{\lambda \in \Lambda})(l_i) = (f_\lambda(l_i))_{\lambda \in \Lambda} = (\pi_\lambda(g(l_i)))_{\lambda \in \Lambda} = g(l_i)`$ for each generator $l_i$. Since the generators span $L$, it follows that $\Phi((f_\lambda)_{\lambda \in \Lambda}) = g$. Thus, $\Phi$ is surjective.
