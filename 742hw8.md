# 11.19
Let $R$ be a ring, $S$ a multiplicative subset. Prove $S^{-1}R = 0$ if and only if $S$ contains a nilpotent element.

**Proof**

($\Rightarrow$) Assume $S^{-1}R = 0$. This means that for every element $r \in R$, there exists an element $s \in S$ such that $s \cdot r = 0$. In particular, for the element $1 \in R$, there exists an element $s_0 \in S$ such that $s_0 \cdot 1 = 0$, which implies that $s_0 = 0$. Since $s_0$ is in $S$, we have found a nilpotent element in $S$.

($\Leftarrow$) Now assume that $S$ contains a nilpotent element, say $s_0$. Since $S$ is a multiplicative subset, all powers of $s_0$ are also in $S$. Let $n$ be the smallest positive integer such that $s_0^n = 0$. Then $S^{-1}R = 0$ because for any element $r \in R$, we have $s_0^n \cdot r = 0$. Therefore, $S^{-1}R = 0$.
