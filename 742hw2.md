# Exercise (1.22)
First, given a prime number $p$ and a $k \geq 1$, find the idempotents in $\mathbb{Z} /\left\langle p^k\right\rangle$. Second, find the idempotents in $\mathbb{Z} /\langle 12\rangle$. Third, find the number of idempotents in $\mathbb{Z} /\langle n\rangle$ where $n=\prod_{i=1}^N p_i^{n_i}$ with $p_i$ distinct prime numbers.

**Proof**
1. In the ring $\mathbb{Z} /\left\langle p^k\right\rangle$, the only idempotents are $\overline{0}$ and $\overline{1}$. This is because if $\overline{a}$ is an idempotent, then $a^2 \equiv a \mod p^k$, which implies $p^k$ divides $a(a-1)$. Since $a$ and $a-1$ are coprime, either $p^k$ must divide $a$ or $p^k$ must divide $a-1$. This means either $a \equiv 0 \mod p^k$ or $a \equiv 1 \mod p^k$.
2. In $\mathbb{Z} /\langle 12\rangle$, the idempotents are $\overline{0}, \overline{1}, \overline{4},$ and $\overline{9}$. This is because solving $a^2 \equiv a \mod 12$ leads to the system of congruences $a^2 \equiv a \mod 3$ and $a^2 \equiv a \mod 4$. By 1, the solutions modulo 3 are $\overline{0}$ and $\overline{1}$, and modulo 4 are $\overline{0}$ and $\overline{1}$. Combining these gives the four idempotents.
3. By the Chinese Remainder Theorem, $\mathbb{Z} /\langle n\rangle \cong \prod_{i=1}^N \mathbb{Z} /\left\langle p_i^{n_i}\right\rangle$. Each factor has 2 idempotents (0 and 1), so the total number of idempotents in $\mathbb{Z} /\langle n\rangle$ is $2^N$.

# Exercise (1.24)
Let $R$ be a ring; $e, e'$ idempotents (see (10.23) also). Show:
1. Set $\mathfrak{a}:=\langle e\rangle$. Then $\mathfrak{a}$ is idempotent; that is, $\mathfrak{a}^2=\mathfrak{a}$.
2. Let $\mathfrak{a}$ be a principal idempotent ideal. Then $\mathfrak{a}=\langle f\rangle$ with $f$ idempotent.
3. Set $e'':=e+e'-e e'$. Then $\left\langle e, e'\right\rangle=\left\langle e''\right\rangle$, and $e''$ is idempotent.
4. Let $e_1, \ldots, e_r$ be idempotents. Then $\left\langle e_1, \ldots, e_r\right\rangle=\langle f\rangle$ with $f$ idempotent.
5. Assume $R$ is Boolean. Then every finitely generated ideal is principal.

**Proof**
1. Let $\mathfrak{a} = \langle e \rangle$. Since $\mathfrak{a}$ is an ideal, $\mathfrak{a}^2 \subseteq \mathfrak{a}$. Conversely, $e=e^2 \in \mathfrak{a}^2$, so $\mathfrak{a} = \langle e \rangle \subseteq \mathfrak{a}^2$ as $\mathfrak{a}^2$ is an ideal. Thus $\mathfrak{a}^2 = \mathfrak{a}$.
2. Let $I=(a)$ be a principal idempotent ideal. Then $I=I^2$, so $(a)=(a)^2=(a^2)$. This implies $a \in (a^2)$, so there exists $r \in R$ such that $a = r a^2$.
    
    Set $f = r a$. Then $a = r a^2 = (r a) a = f a$.
    
    It follows that $f$ is idempotent, as $f^2 = f(ra) = r(fa) = ra = f$.
    
    Furthermore, since $a = f a \in (f)$, we have $(a) \subseteq (f)$. Since $f \in (a)$, $(f) \subseteq (a)$.
    
    Therefore, $I = (a) = (f)$.
3. The element $e'' = e + e' - ee'$ is idempotent: $e''^2 = (e+e'-ee')^2 = e^2+(e')^2+(ee')^2+2ee'-2e(ee')-2e'(ee') = e+e'+ee'+2ee'-2ee'-2ee' = e+e'-ee' = e''$. In that case, the ideal equality $\langle e, e' \rangle = \langle e'' \rangle$ holds. This is because $e'' \in \langle e, e' \rangle$, and conversely $e, e' \in \langle e'' \rangle$ since $ee''=e$ and $e'e''=e'$. Thus, the ideal is principal.
4. We prove by induction on $r$ that an ideal generated by a set of $r$ pairwise commuting idempotents is principal.
   *   **Base case ($r=2$):** This is part 3.
   *   **Inductive step:** Assume an ideal with $r-1$ pairwise commuting idempotent generators is principal, say $\langle e_1, \dots, e_{r-1} \rangle = \langle f \rangle$. Then $\langle e_1, \dots, e_r \rangle = \langle f, e_r \rangle$. By the base case, $\langle f, e_r \rangle$ is principal.
5. In a Boolean ring, every element is idempotent. A finitely generated ideal $\langle a_1, \dots, a_r \rangle$ is generated by idempotents. By part 4, this ideal is principal.
# Exercise (2.29)
Let $R:=R' \times R''$ be a product of rings, $\mathfrak{p} \subset R$ an ideal. Show $\mathfrak{p}$ is prime if and only if either $\mathfrak{p}=\mathfrak{p}' \times R''$ with $\mathfrak{p}' \subset R'$ prime or $\mathfrak{p}=R' \times \mathfrak{p}''$ with $\mathfrak{p}'' \subset R''$ prime.

**Proof**

First, assume $\mathfrak{p}$ is a prime ideal in $R = R' \times R''$. Since $(1,0)(0,1) = 0 \in \mathfrak{p}$, we must have $(1,0) \in \mathfrak{p}$ or $(0,1) \in \mathfrak{p}$. They cannot both be in $\mathfrak{p}$, as that would imply $(1,1) \in \mathfrak{p}$ and $\mathfrak{p}=R$.
- If $(0,1) \in \mathfrak{p}$, then $\mathfrak{p} = \mathfrak{p}' \times R''$ where $`\mathfrak{p}' = \{a' \in R' \mid (a', 0) \in \mathfrak{p}\}`$. The quotient $R/\mathfrak{p} \cong R'/\mathfrak{p}'$. Since $R/\mathfrak{p}$ is an integral domain, so is $R'/\mathfrak{p}'$, which means $\mathfrak{p}'$ is prime.
- If $(1,0) \in \mathfrak{p}$, a symmetric argument shows $\mathfrak{p} = R' \times \mathfrak{p}''$ for a prime ideal $\mathfrak{p}'' \subset R''$.

Conversely, assume $\mathfrak{p} = \mathfrak{p}' \times R''$ for a prime ideal $\mathfrak{p}' \subset R'$. Then $R/\mathfrak{p} \cong R'/\mathfrak{p}'$. Since $\mathfrak{p}'$ is prime, $R'/\mathfrak{p}'$ is an integral domain, so $R/\mathfrak{p}$ is an integral domain, and $\mathfrak{p}$ is prime. The case $\mathfrak{p} = R' \times \mathfrak{p}''$ is symmetric.

# Exercise (2.33)
Let $R$ be a ring, $X$ a variable, $H \in P:=R[X]$, and $a \in R$. Given $n \geq 1$, show $(X-a)^n$ and $H$ are coprime if and only if $H(a)$ is a unit.

**Proof**

By [HW1](742hw1.md) question 3.3, $(X-a)^n$ and $H$ are coprime if and only if $X-a$ and $H$ are coprime.

If $X-a$ and $H$ are coprime, then there exist $F, G \in R[X]$ such that $F(X)(X-a) + G(X)H(X) = 1$. Evaluating at $X=a$ gives $G(a)H(a)=1$, so $H(a)$ is a unit.

Conversely, if $H(a)$ is a unit, then $H(X) \equiv H(a) \pmod{X-a}$. This implies $H(a)^{-1}H(X) \equiv 1 \pmod{X-a}$, so $1$ can be written as a linear combination of $H(X)$ and $X-a$. Thus, they are coprime.

# Exercise (2.36)
Let $B$ be a Boolean ring. Show that every prime $\mathfrak{p}$ is maximal, and that $B / \mathfrak{p}=\mathbb{F}_2$.

**Proof**

If $\mathfrak{p}$ is a prime ideal, then the quotient $B/\mathfrak{p}$ is an integral domain. Since the property $a^2 = a$ for all $a$ is preserved under quotients, $B/\mathfrak{p}$ is also a Boolean ring, and every element $a$ satisfies $a(a - 1) = a^2 - a = 0$. In an integral domain, if $a \neq 0$, then $a - 1 = 0$, so $a = 1$. Thus, the only elements of $B/\mathfrak{p}$ are $0$ and $1$, and $B/\mathfrak{p} \cong \mathbb{F}_2$. Therefore, $B/\mathfrak{p}$ is a field, which implies that $\mathfrak{p}$ is maximal.
# Problem A
An $R$-algebra $S$ is said to be finitely generated if it is isomorphic to a quotient of a polynomial algebra $R\left[x_1, \ldots, x_n\right]$ for some integer $n$.

Show that a quotient of a finitely generated algebra must be finitely generated.

**Proof**

Let $S$ be a finitely generated $R$-algebra. By the definition provided, there is a surjective $R$-algebra homomorphism $\phi: R[x_1, \ldots, x_n] \to S$. 

Let $I$ be an ideal of $S$. The canonical projection $\pi: S \to S/I$ is also a surjective $R$-algebra homomorphism. 

The composition $\pi \circ \phi: R[x_1, \ldots, x_n] \to S/I$ is therefore a surjective homomorphism. 

This shows that $S/I$ is a quotient of $R[x_1, \ldots, x_n]$, and thus is finitely generated by definition.

# Problem B
Show that the set $\mathbb{R}+(x y) \subset \mathbb{R}[x, y]$ is an $\mathbb{R}$-subalgebra, and that it is not finitely generated. This shows that a subalgebra of a finitely generated algebra need not be finitely generated.

**Proof**

- Verification as a Subalgebra
    
    The set is $S = k + xy \cdot k[x,y]$, consisting of all polynomials in $k[x,y]$ with an arbitrary constant term and all non-constant terms divisible by $xy$. This generalizes the problem from $\mathbb{R}$ to a field $k$.
    
    This set can be expressed as $`S = \{ c + xy \cdot g \mid c \in k,\ g \in k[x,y] \}`$.
    
    $S$ is a $k$-vector subspace of $k[x,y]$ (closed under addition and scalar multiplication) and contains $1 = 1 + xy \cdot 0$.
    
    To confirm closure under multiplication, consider $f = c + xy \cdot g$ and $f' = d + xy \cdot h$. Their product is:
    $ff' = (c + xy g)(d + xy h) = cd + xy (ch + dg + xygh) \in S.$
    Thus, $S$ is a $k$-subalgebra of $k[x,y]$.

- Not finitely generated
  
  Assume, for contradiction, that $S = k[f_1, \dots, f_r]$ is finitely generated. Each generator is of the form $f_i = c_i + xy \cdot g_i$ for some $c_i \in k$ and $g_i \in k[x,y]$.
  
  Let $d$ be the maximum degree of any polynomial $g_i(x,0)$ (i.e., $g_i$ with $y$ set to 0) for $i=1, \dots, r$.
  
  Now consider the element $h = x^{d+2}y = xy \cdot x^{d+1} \in S$. As $h \in S$, it must be a polynomial expression $P(f_1, \dots, f_r)$.
  
  Any element $h \in S$ can be written as $h = c + xy \cdot G$ for some $c \in k$ and $G \in k[x,y]$. If $h=P(f_1, \dots, f_r)$, then $c=P(c_1, \dots, c_r)$ and $G$ is a polynomial expression involving the $g_i$. Specifically, $G \equiv \sum_j \alpha_j g_j \pmod{xy}$ for some scalars $\alpha_j \in k$.
  
  Setting $y=0$, we get $G(x,0) = \sum_i \alpha_i g_i(x,0)$. The degree of the right side is at most $d$ because $\deg g_i(x,0)\le d$.
  
  For our chosen element $h = x^{d+2}y$, we have $G = x^{d+1}$. So $G(x,0) = x^{d+1}$, which has degree $d+1$.
  
  This gives $d+1 \le d$, a contradiction. Therefore, $S$ is not finitely generated.
