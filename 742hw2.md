# Exercise (1.24)
Let $R$ be a ring; $e, e'$ idempotents (see (10.23) also). Show:
1. Set $\mathfrak{a}:=\langle e\rangle$. Then $\mathfrak{a}$ is idempotent; that is, $\mathfrak{a}^2=\mathfrak{a}$.
2. Let $\mathfrak{a}$ be a principal idempotent ideal. Then $\mathfrak{a}=\langle f\rangle$ with $f$ idempotent.

This join is computed iteratively using the binary operation $x + y + xy$ (in characteristic 2). For two generators $x$ and $y$, the join is the element $z = x + y + xy$, which is idempotent: since the ring has characteristic 2, cross terms vanish in the expansion, yielding $(x + y + xy)^2 = x^2 + y^2 + (xy)^2 = x + y + xy$ (as $(xy)^2 = xy$ by idempotence).

The ideal equality $\langle x, y \rangle = \langle z \rangle$ holds because $z = x + y + xy \in \langle x, y \rangle$ obviously, while conversely $x z = x(x + y + xy) = x + xy + x^2 y = x + xy + xy = x$ (in characteristic 2), and similarly $y z = y$, so $x, y \in \langle z \rangle$. The result for $n$ generators follows by induction.
