The following problems are based on the material from week 2.
1. Let $B \in \Gamma(\mathrm{End} E)$ be a section, with local components $B^\alpha{ }_\beta$.
    
    Suppose that $\sigma=\left(\sigma^\alpha{ }_\beta\right)$ is a change-of-frame. Show that, in matrix notation, the components of $B$ in the new frame are given by
    
    $B'=\sigma \cdot B \cdot \sigma^{-1} .$
    
    **Proof**
    
    Let a vector have components $x$ in the original frame and $x'$ in the new frame. The change-of-frame matrix $\sigma$ transforms the components from the old frame to the new one:
    $$x' = \sigma x$$
    This implies that to transform from the new frame back to the old one, we use the inverse matrix $\sigma^{-1}$:
    $$x = \sigma^{-1} x'$$

    Now, consider the action of the operator $B$ in the original frame, which is described by the equation:
    $$y = Bx$$
    We want to find the operator $B'$ in the new frame such that:
    $$y' = B'x'$$

    To find the relationship between $B$ and $B'$, we can express $y = Bx$ in terms of the new components $x'$ and $y'$.
    1.  Start with the relation in the old frame: $y = Bx$.
    2.  Transform the components to the new frame. We know $y' = \sigma y$, so $y = \sigma^{-1} y'$. And we have $x = \sigma^{-1} x'$.
    3.  Substitute these into the equation:
        $$\sigma^{-1} y' = B (\sigma^{-1} x')$$
    4.  To isolate $y'$, multiply both sides by $\sigma$ from the left:
        $$\sigma (\sigma^{-1} y') = \sigma (B \sigma^{-1} x')$$
        $$y' = (\sigma B \sigma^{-1}) x'$$

    By comparing this result with the definition $y' = B'x'$, we can identify the components of the operator in the new frame as:
    $$B' = \sigma B \sigma^{-1}$$
    This completes the proof.

    *Note: This transformation rule is "homogeneous." In contrast, non-tensorial objects (like the Christoffel symbols in differential geometry) have an additional non-homogeneous term in their transformation law because they also account for how the basis itself changes from point to point.*
2. For any two connections $\nabla, \nabla' \in \mathcal{A}(E)$ and any smooth function $\lambda \in C^\infty(M,[0,1])$, the operator
    
    $\nabla_\lambda := \lambda \nabla + (1-\lambda) \nabla'$
    
    is a connection on $E$.
    
    **Proof**
    
    For $s \in \Gamma(E)$ and $X \in \Gamma(TM)$,
    
    $(\nabla_\lambda)_X s = \lambda (\nabla_X s) + (1-\lambda) (\nabla'_X s).$
    
    This satisfies the Leibniz rule: for $f \in C^\infty(M)$,
    
    $\nabla_\lambda (f s) = \lambda \nabla (f s) + (1-\lambda) \nabla' (f s) = \lambda (f \nabla s + df \otimes s) + (1-\lambda) (f \nabla' s + df \otimes s) = f (\lambda \nabla s + (1-\lambda) \nabla' s) + df \otimes s = f (\nabla_\lambda s) + df \otimes s.$
    
    Linearity over constants is immediate from the linearity of $\nabla$ and $\nabla'$. Thus, $\nabla_\lambda$ is a connection.
