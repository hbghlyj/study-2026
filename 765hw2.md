1. Let $B \in \Gamma(\mathrm{End} E)$ be a section, with local components $B^\alpha{}_\beta$.
    
    Suppose that $\sigma=\left(\sigma^\alpha{}_\beta\right)$ is a change-of-frame. Show that, in matrix notation, the components of $B$ in the new frame are given by
    
    $B'=\sigma \cdot B \cdot \sigma^{-1} .$
    
    **Proof**
    
    Let a vector have components $x$ in the original frame and $x'$ in the new frame. The change-of-frame matrix $\sigma$ transforms the components from the old frame to the new one:
    
    $$x' = \sigma x$$
    
    This implies that to transform from the new frame back to the old one, we use the inverse matrix $\sigma^{-1}$:
    
    $$x = \sigma^{-1} x'$$

    Now, consider the action of the operator $B$ in the original frame, which is described by the equation:
    
    $$y = Bx$$
   
    We want to find the operator $B'$ in the new frame such that:

    $$y' = B'x'$$
        
    To find the relationship between $B$ and $B'$, we can derive it by substituting the known relations:
    
    $$y' = \sigma y = \sigma (Bx) = \sigma B (\sigma^{-1} x') = (\sigma B \sigma^{-1}) x'$$
    
    By comparing this result with the definition $y' = B'x'$, we can identify the components of the operator in the new frame as:
    
    $$B' = \sigma B \sigma^{-1}$$

3. Consider the connection $\nabla$ defined on the product bundle $\underline{\mathbb{R}}\rightarrow \mathbb{R}^1$ with connection matrix

    $A_1(x)=\frac{1}{1+x^2} .$
    
    Write down a parallel (i.e. covariantly constant) global section.

    **Proof**

    A parallel global section $s = s^1(x) e_1$ must satisfy $\nabla_{\frac{\partial}{\partial x^1}} (s^1 e_1) = 0$.
    
    Applying the Leibniz rule and using the given connection where $\nabla_{\frac{\partial}{\partial x^1}} e_1 = \frac{1}{1+x^2}e_1$, we get the differential equation:
    
    $\frac{ds^1}{dx^1} + \frac{s^1}{1+(x^1)^2} = 0$
    
    Solving this separable ODE gives $s^1(x^1) = C e^{-\arctan(x^1)}$.
    
    Thus, a parallel global section (with constant $C=1$) is $s(x) = e^{-\arctan(x^1)} e_1$.
4. Write down an obvious connection on the Möbius bundle. (Note: you should not need to use a partition of unity.)

    **Proof**
   
   The total space $E$ is defined by the quotient of $\mathbb{R} \times \mathbb{R}$ under the relation $(t, v) \sim (t + 1, -v)$. In the local coordinate chart $(t, v)$ on the covering space $\mathbb{R} \times \mathbb{R}$, a section $s: S^1 \to E$ can be represented by a smooth function $v(t)$ that satisfies the boundary condition $v(t+1) = -v(t)$.

    In the local coordinates $(t, v)$, define a covariant derivative
    
    $\nabla_{\frac{\partial}{\partial t}} s = \frac{dv}{dt}$
    
    To check that this definition is well-defined, we must verify that if $s$ is a section, then $\nabla_{\frac{\partial}{\partial t}} s$ is also a section. A function $w(t)$ represents a section if it satisfies the boundary condition $w(t+1) = -w(t)$.

    Let $s$ be represented by $v(t)$, so $v(t+1) = -v(t)$. The covariant derivative is represented by $w(t) = \frac{dv}{dt}$. Differentiating the condition for $v(t)$ with respect to $t$ gives:

    $$\frac{d}{dt}v(t+1) = -\frac{dv}{dt}(t)$$

    By the chain rule, this is $v'(t+1) = -v'(t)$, which means $w(t+1) = -w(t)$. Thus, $\nabla_{\frac{\partial}{\partial t}} s$ is a well-defined section.

6. Given a connection $\nabla$ on $E$ and a global endomorphism $\sigma \in \Gamma(\mathrm{End} E)$, consider the connection $\nabla'$ defined by
    
    $\nabla'(s)=\sigma \nabla\left(\sigma^{-1} s\right)$
    
    for $s \in \Gamma(E)$.

    (a) Check that $\nabla'$ is a connection
    
    (b) Let $`\left\{e_\alpha\right\}`$ be any local frame for $E$, and let $A_i, A_i'$ be the connection coefficients of $\nabla$ and $\nabla'$, respectively, in this frame. Show that the connection matrices are related by
    
    $A_i'=\sigma A_i \sigma^{-1}-\frac{\partial \sigma}{\partial x^i} \sigma^{-1},$
    
    where we use matrix notation.

    **Proof**

    (a) $\nabla'$ is $\mathbb{R}$-linear in $s$ because both $\nabla$ and multiplication by $\sigma$ are $\mathbb{R}$-linear. $\nabla'$ is $C^\infty(M)$-linear in $X$ because both $\nabla$ and multiplication by $\sigma$ are $C^\infty(M)$-linear in $X$. Finally, $\nabla'$ satisfies the Leibniz rule:
    $`\begin{aligned}
    \nabla'_X (f s) &= \sigma \nabla_X (\sigma^{-1} (f s)) \\
    &= \sigma \nabla_X (f \sigma^{-1} s) \\
    &= \sigma (X(f) \sigma^{-1} s + f \nabla_X (\sigma^{-1} s)) \\
    &= (X(f)) s + f \sigma \nabla_X (\sigma^{-1} s) \\
    &= (X(f)) s + f \nabla'_X s
    \end{aligned}`$
    
    for $f \in C^\infty(M)$ and $s \in \Gamma(E)$.
    
    (b) Let $\{e_\alpha\}$ and $\{e'_\beta\}$ be two local frames over $U$, with the change-of-frame matrix $\sigma$ defined by:

    $`e_\alpha = \sigma^{\beta}{}_\alpha \, e'_\beta.`$

    We compute how the connection matrices transform under a change of frame. On one hand, we have
    
    $`\begin{split}\nabla_{\frac{\partial}{\partial x^i}} e_\alpha  & = \nabla_{\frac{\partial}{\partial x^i}}(\sigma^{\beta}{}_\alpha e'_\beta) \\ & = \frac{\partial \sigma^{\beta}{}_\alpha}{\partial x^i} e'_\beta + \sigma^{\beta}{}_\alpha\, \nabla_{\frac{\partial}{\partial x^i}} e'_\beta \\ & = \left(\frac{\partial \sigma^{\gamma}{}_\alpha}{\partial x^i} + \sigma^{\beta}{}_\alpha A'^\gamma_{i \beta} \right)e'_\gamma.\end{split}`$
    
    On the other hand, we have
    
    $`\nabla_{\frac{\partial}{\partial x^i}} e_\alpha= A^\beta_{i \alpha}\, e_\beta = A^\beta_{i \alpha}\, \sigma^{\gamma}{}_\beta e'_\gamma.`$
    
    Comparing coefficients of $e'_\gamma$, we get
    
    $`A^\beta_{i \alpha}\, \sigma^{\gamma}{}_\beta= \frac{\partial \sigma^{\gamma}{}_\alpha}{\partial x^i}+ \sigma^{\beta}{}_\alpha A'^\gamma_{i \beta}.`$
    
    In matrix notation, this becomes
    
    $`\sigma \cdot A_i = \frac{\partial \sigma}{\partial x^i} + A'_i \cdot \sigma.`$
    
    Multiplying on the right by $\sigma^{-1}$ and rearranging, we obtain
    
    $A'_i = \sigma \cdot A_i \cdot \sigma^{-1}- \frac{\partial \sigma}{\partial x^i} \cdot \sigma^{-1}.$
