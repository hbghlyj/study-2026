The following two problems are about the composite of fields, defined in the textbook.

# Problem A
Let $F, E_1$, and $E_2$ be subfields of $K$. Suppose $E_1 \supset F$ and $E_2 \supset F$. Show that if $E_1 / F$ is a finite extension, then so is $E_1 E_2 / E_2$, and moreover, $\left[E_1 E_2: E_2\right] \leq\left[E_1: F\right]$.

# Problem B
In the situation of the previous problem, show that if $E_1 / F$ is algebraic, then so is $E_1 E_2 / E_2$.
