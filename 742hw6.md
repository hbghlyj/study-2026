# Problem 8.22
Let $R$ be a domain, $\mathfrak{a}$ a nonzero ideal. Set $K:=\operatorname{Frac}(R)$. Show that $\mathfrak{a} \otimes_R K=K$.

**Proof.** Since $\mathfrak{a}$ is a nonzero ideal of the domain $R$, it contains a nonzero element $a$. Consider the map $\phi: \mathfrak{a} \otimes_R K \rightarrow K$ descending from the bilinear map $\mathfrak{a} \times K \rightarrow K$ given by $(x, k) \mapsto xk$. This map is well-defined and $R$-linear. To show that $\phi$ is an isomorphism, we first show that it is surjective. For any $k \in K$, we can write $k = r/s$ for some $r \in R$ and $s \in R \setminus \{0\}$. Then $\phi(a \otimes \frac{r}{sa}) = a \cdot \frac{r}{sa} = \frac{ar}{sa} = k$, showing that $\phi$ is surjective. Next, we show that $\phi$ is injective. Suppose an element $\sum_i x_i \otimes k_i \in \mathfrak{a} \otimes_R K$ is in the kernel of $\phi$. This means $\sum_i x_i k_i = 0$ in $K$. We can find a common denominator $s \in R \setminus \{0\}$ for all $k_i$, so that $k_i = r_i/s$ for some $r_i \in R$. The condition becomes $(\sum_i x_i r_i)/s = 0$, which implies $\sum_i x_i r_i = 0$ in $R$ since $R$ is a domain. The original element in the tensor product can be rewritten as $\sum_i x_i \otimes \frac{r_i}{s} = (\sum_i x_i r_i) \otimes \frac{1}{s} = 0 \otimes \frac{1}{s} = 0$. Thus, $\phi$ is injective, and therefore an isomorphism.

# Problem A

Show that the functor is represented by $a \in \mathcal{C}$ if and only if there exists an element $\alpha \in F(a)$ with the following property: for any $b \in \mathcal{C}$ and any $\beta$ in $F(b)$, there exists unique $f: a \rightarrow b$ such that $F(f)(\alpha)=\beta$.
