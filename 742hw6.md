# Problem 8.22
Let $R$ be a domain, $\mathfrak{a}$ a nonzero ideal. Set $K:=\operatorname{Frac}(R)$. Show that $\mathfrak{a} \otimes_R K=K$.
# Problem 8.27
Let $R$ be a ring, $\mathfrak{a}$ and $\mathfrak{b}$ ideals, and $M$ a module.
1. Use (8.10) to show that $(R / \mathfrak{a}) \otimes M=M / \mathfrak{a} M$.
2. Use (1) and (4.21) to show that $(R / \mathfrak{a}) \otimes(M / \mathfrak{b} M)=M /(\mathfrak{a}+\mathfrak{b}) M$.
# Problem 8.31
Let $R$ be a ring, $M$ a module, $X$ a set of variables. Prove the equation $M \otimes_R R[\mathcal{X}]=M[\mathcal{X}]$.
# Problem A
Let $F$ be a functor from a category $\mathcal{C}$ to $\mathcal{S}$ ets. Show that the functor is represented by $a \in \mathcal{C}$ if and only if there exists an element $\alpha \in F(a)$ with the following property: for any $b \in \mathcal{C}$ and any $\beta$ in $F(b)$, there exists unique $f: a \rightarrow b$ such that $F(f)(\alpha)=\beta$.
(This can be viewed as a reformulation of representability of functors as a universal mapping property. Consider what this says if $F$ is, say, the functor represented by the tensor product.)

The following problems talk about representability for contravariant functors. A contravariant functor is represented by an object $a$ if it is of the form $\operatorname{Hom}(-, a)$.

# Problem B
For every set $X$, its power set $P(X)$ is the set of all subsets of $X$. It can be viewed as a contravariant functor from the category of sets to itself via preimage of subsets (Make sure you understand what this means!) Is this functor representable?

# Problem C
Fix two abelian groups $M$ and $N$, and consider the following contravariant functor from abelian groups to sets: to a group $X$ it assigns the set of all $\mathbb{Z}$-bilinear maps $X \times M \rightarrow N$. Is this functor representable?
