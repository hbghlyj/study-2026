# Problem 8.22
Let $R$ be a domain, $\mathfrak{a}$ a nonzero ideal. Set $K:=\operatorname{Frac}(R)$. Show that $\mathfrak{a} \otimes_R K=K$.

**Proof.** Since $\mathfrak{a}$ is a nonzero ideal of the domain $R$, it contains a nonzero element $a$. Consider the map $\phi: \mathfrak{a} \otimes_R K \rightarrow K$ descending from the bilinear map $\mathfrak{a} \times K \rightarrow K$ given by $(x, k) \mapsto xk$. This map is well-defined and $R$-linear. To show that $\phi$ is an isomorphism, we first show that it is surjective. For any $k \in K$, we can write $k = r/s$ for some $r \in R$ and $s \in R \setminus \{0\}$. Then $\phi(a \otimes \frac{r}{sa}) = a \cdot \frac{r}{sa} = \frac{ar}{sa} = k$, showing that $\phi$ is surjective. Next, we show that $\phi$ is injective. Suppose $\phi(\sum_i x_i \otimes k_i) = 0$ for some $x_i \in \mathfrak{a}$ and $k_i \in K$. This means that $\sum_i x_i k_i = 0$ in $K$. Since $K$ is the field of fractions of $R$, this implies that there exists a nonzero element $s \in R$ such that $s \sum_i x_i k_i = 0$ in $R$. But since $x_i \in \mathfrak{a}$ and $\mathfrak{a}$ is an ideal, we have $s x_i \in \mathfrak{a}$ for all $i$. Thus, we can write $s x_i = a y_i$ for some $y_i \in R$. Substituting back, we get $\sum_i a y_i k_i = 0$, which implies that $\sum_i y_i k_i = 0$ in $K$. Since $K$ is a field, this means that each $y_i k_i = 0$, and hence each $y_i = 0$. Therefore, each $x_i = 0$, and thus $\sum_i x_i \otimes k_i = 0$ in $\mathfrak{a} \otimes_R K$. This shows that $\phi$ is injective, and therefore an isomorphism.
