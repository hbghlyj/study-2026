# Problem 8.22
Let $R$ be a domain, $\mathfrak{a}$ a nonzero ideal. Set $K:=\operatorname{Frac}(R)$. Show that $\mathfrak{a} \otimes_R K=K$.

**Proof.** Since $\mathfrak{a}$ is a nonzero ideal of the domain $R$, it contains a nonzero element $a$. Consider the map $\phi: \mathfrak{a} \otimes_R K \rightarrow K$ descending from the bilinear map $\mathfrak{a} \times K \rightarrow K$ given by $(x, k) \mapsto xk$. This map is well-defined and $R$-linear. To show that $\phi$ is an isomorphism, we first show that it is surjective. For any $k \in K$, we can write $k = r/s$ for some $r \in R$ and $`s \in R \setminus \{0\}`$. Then $\phi(a \otimes \frac{r}{sa}) = a \cdot \frac{r}{sa} = \frac{ar}{sa} = k$, showing that $\phi$ is surjective. Next, we show that $\phi$ is injective. Suppose an element $\sum_i x_i \otimes k_i \in \mathfrak{a} \otimes_R K$ is in the kernel of $\phi$. This means $\sum_i x_i k_i = 0$ in $K$. We can find a common denominator $`s \in R \setminus \{0\}`$ for all $k_i$, so that $k_i = r_i/s$ for some $r_i \in R$. The condition becomes $(\sum_i x_i r_i)/s = 0$, which implies $\sum_i x_i r_i = 0$ in $R$ since $R$ is a domain. The original element in the tensor product can be rewritten as $\sum_i x_i \otimes \frac{r_i}{s} = (\sum_i x_i r_i) \otimes \frac{1}{s} = 0 \otimes \frac{1}{s} = 0$. Thus, $\phi$ is injective, and therefore an isomorphism.

# Problem 8.31
Let $R$ be a ring, $M$ a module, $\cal X$ a set of variables. Prove the equation $M \otimes_R R[\mathcal{X}]=M[\mathcal{X}]$.

**Proof**

Let $\mathcal{M}$ be the set of monomials in variables from $\mathcal{X}$. As an $R$-module, $R[\mathcal{X}] \cong \bigoplus_{u \in \mathcal{M}} R$. Since tensor products distribute over direct sums, we have

$ M \otimes_R R[\mathcal{X}] \cong M \otimes_R \left(\bigoplus_{u \in \mathcal{M}} R\right) \cong \bigoplus_{u \in \mathcal{M}} (M \otimes_R R) \cong \bigoplus_{u \in \mathcal{M}} M $

By definition, $M[\mathcal{X}]$, the module of polynomials with coefficients in $M$, is also $\bigoplus_{u \in \mathcal{M}} M$. Thus, $M \otimes_R R[\mathcal{X}] \cong M[\mathcal{X}]$.
# Problem A
Let $F$ be a functor from a category $\mathcal{C}$ to $\text{Sets}$. Show that the functor is represented by $a \in \mathcal{C}$ if and only if there exists an element $\alpha \in F(a)$ with the following property: for any $b \in \mathcal{C}$ and any $\beta$ in $F(b)$, there exists unique $f: a \rightarrow b$ such that $F(f)(\alpha)=\beta$.

(This can be viewed as a reformulation of representability of functors as a universal mapping property. Consider what this says if $F$ is, say, the functor represented by the tensor product.)

**Proof**

($\Rightarrow$) Suppose $F$ is representable by $a \in \cal C$. By definition, there is a natural isomorphism $\eta: F \to h_a$. Let $\alpha := \eta^{-1}_a(\mathrm{id}_a) \in F(a)$.

For any $b \in \mathcal{C}$ and $\beta \in F(b)$, let $f=\eta_b(\beta)$. By naturality, $F(f)(\alpha) = F(f)(\eta^{-1}_a(\mathrm{id}_a)) = \eta^{-1}_b(f \circ \mathrm{id}_a) = \eta^{-1}_b(f) = \beta$. Thus, the existence and uniqueness of such an $f$ is established.

($\Leftarrow$) Assume the property holds for some $\alpha \in F(a)$. For each $b \in \mathcal{C}$, define a map $\eta_b: F(b) \to h_a(b)$ by sending $\beta \in F(b)$ to the unique morphism $f: a \to b$ such that $F(f)(\alpha) = \beta$. The uniqueness condition ensures this map is a bijection. To show naturality, consider a morphism $g: b \to c$. For any $\beta \in F(b)$, let $f = \eta_b(\beta)$. We must show $\eta_c(F(g)(\beta)) = g \circ f$. The left side is the unique morphism $h$ such that $F(h)(\alpha) = F(g)(\beta)$. Since $F(g)(\beta) = F(g)(F(f)(\alpha)) = F(g \circ f)(\alpha)$, by uniqueness we have $h = g \circ f$. Thus $\eta$ is a natural isomorphism.

# Problem B
For every set $X$, its power set $P(X)$ is the set of all subsets of $X$. It can be viewed as a contravariant functor from the category of sets to itself via preimage of subsets (Make sure you understand what this means!) Is this functor representable?

**Proof**

Yes, this functor is representable. We show it is naturally isomorphic to $`\operatorname{Hom}(-, \{0,1\})`$.

For any set $X$, define $`\eta_X: P(X) \to \operatorname{Hom}(X, \{0,1\})`$ by mapping a subset $S \subseteq X$ to its characteristic function $\chi_S$. This is a bijection for each $X$.

For naturality, consider a map $f: X \to Y$. We need to show $`\eta_X \circ P(f) = \operatorname{Hom}(f, \{0,1\}) \circ \eta_Y`$ where $`\operatorname{Hom}(f, \{0,1\})`$ is precomposing with $f$. For any $T \subseteq Y$, we check if $\chi_{f^{-1}(T)} = \chi_T \circ f$. For any $x \in X$, $\chi_{f^{-1}(T)}(x) = 1 \iff x \in f^{-1}(T) \iff f(x) \in T$. Also, $(\chi_T \circ f)(x) = \chi_T(f(x)) = 1 \iff f(x) \in T$. The two functions are identical, so the isomorphism is natural.

# Problem C
Fix two abelian groups $M$ and $N$, and consider the following contravariant functor from abelian groups to sets: to a group $X$ it assigns the set of all $\mathbb{Z}$-bilinear maps $X \times M \rightarrow N$. Is this functor representable?

**Proof**

Yes, this functor is representable. We show this functor is naturally isomorphic to $\operatorname{Hom}(-, \operatorname{Hom}(M, N))$.

For any group $X$, define $\eta_X: \operatorname{Bilin}(X \times M,N) \to \operatorname{Hom}(X,\operatorname{Hom}(M, N))$ by mapping $f$ to $x\mapsto f(x,-)$.

$\eta_X$ is well-defined. For a bilinear map $f$, linearity in the second argument implies that for each $x \in X$, $f(x,-) \in \operatorname{Hom}(M, N)$. Linearity in the first argument implies that the map $x \mapsto f(x,-)$ is a homomorphism, so it is in $\operatorname{Hom}(X, \operatorname{Hom}(M,N))$.

$\eta_X^{-1}$ is well-defined because $f(x,-)$ is linear means $f$ is linear in the second argument; $x\mapsto f(x,-)$ is linear means $f$ is linear in the first component.

For naturality, consider a map $f: X \to Y$. We need to show

$\eta_X \circ (f \times \mathrm{id}_M)^*=\operatorname{Hom}(f,\operatorname{Hom}(M, N))\circ\eta_Y$

where $^*$ means the dual map.
