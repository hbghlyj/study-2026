# 5.29
Let $R$ be a ring, $X_1, X_2, \ldots$ infinitely many variables. Set $P:=R[X_1, X_2, \ldots]$ and $M:=P /\langle X_1, X_2, \ldots\rangle$. Is $M$ finitely presented? Explain.

**Proof**

No. First, prove a more general statement: If a module $R/I$ is finitely presented then the ideal $I$ is finitely generated as an $R$-module.

This characterization follows from the short exact sequence $0 \to I \to R \to R/I \to 0$, in which $R$ is free of rank 1. If $R/I$ is finitely presented, there exists an exact sequence $0 \to K \to R^n \to R/I \to 0$ for some integer $n$ and some finitely generated module $K$.

Applying Schanuel's lemma to this sequence and to the canonical exact sequence $0 \to I \to R \to R/I \to 0$, we obtain an isomorphism $R \oplus K \cong R^n \oplus I$. Since $R \oplus K$ is finitely generated (as $R$ is finitely generated and $K$ is finitely generated), $I$ is isomorphic to a quotient of a finitely generated module and hence finitely generated.

In our case, the ring is $P=R[X_1, X_2, \ldots]$ and the ideal is $I = \langle X_1, X_2, \ldots \rangle$. This ideal is not finitely generated: any finite collection of elements from $I$ involves only finitely many variables, so it cannot generate the remaining variables. Therefore, by the statement just proved, the module $M = P/I$ is not finitely presented.

# 5.30
Let $0 \rightarrow L \xrightarrow{\alpha} M \xrightarrow{\beta} N \rightarrow 0$ be a short exact sequence with $M$ finitely generated and $N$ finitely presented. Prove $L$ is finitely generated.

**Proof**

Let $R$ be a ring and consider the short exact sequence $0 \to L \xrightarrow{\alpha} M \xrightarrow{\beta} N \to 0$ where $M$ is a finitely generated $R$-module and $N$ is a finitely presented $R$-module.

Since $M$ is finitely generated, there exists a positive integer $m$ and an $R$-linear surjection $\mu: R^m \to M$. The composition $\beta \circ \mu: R^m \to N$ is then surjective. Since $N$ is finitely presented, the kernel $K = \ker(\beta \circ \mu)$ is finitely generated.

This induces the commutative diagram with exact rows

$\begin{CD} 0 @>>> K @>>> R^m @>>> N @>>> 0 \\ @. @VV \lambda V @VV \mu V @VV \mathrm{id}_N V \\ 0 @>>> L @>>> M @>>> N @>>> 0 \end{CD}$

where $\lambda: K \to L$ is the restriction of $\mu$ to $K$. Elements of $K$ map into $L$ under $\mu$ because $\beta(\mu(k)) = 0$ for $k \in K$, so $\mu(k) \in \ker \beta = L$.

The map $\lambda$ is surjective: let $l \in L$. Since $\mu$ is surjective, there exists $y \in R^m$ such that $\mu(y) = l$. Then $\beta(\mu(y)) = \beta(l) = 0$, so $y \in K$ and $\lambda(y) = l$.
Thus $L$ is the image of the surjective map $\lambda$ from the finitely generated module $K$, so $L$ is finitely generated.

# Problem A
Let $\mathcal{C}$ be an arbitrary category. Consider the category of functors $\mathrm{Fun}(\mathcal{C}, \text{Sets})$. Prove that this category admits products:

for any family of functors $F_\alpha \in \mathrm{Fun}(\mathcal{C}, \text{Sets})$, the product exists.

**Proof**

Let $`\{F_\alpha\}_{\alpha \in I}`$ be a family of functors from $\mathcal{C}$ to $\text{Sets}$. We construct their product functor $P$ and projection natural transformations $\pi_\alpha: P \to F_\alpha$.

1.  **Define the functor $P$**:
    *   For each object $C \in \mathcal{C}$, define $`P(C) = \prod_{\alpha \in I} F_\alpha(C)`$. This is the Cartesian product of sets, which exists in the category of Sets. The elements of $P(C)$ are families $`(x_\alpha)_{\alpha \in I}`$ where $x_\alpha \in F_\alpha(C)$.
    *   For each morphism $f: C \to D$ in $\mathcal{C}$, we define a map $P(f): P(C) \to P(D)$. Since each $F_\alpha$ is a functor, we have maps $F_\alpha(f): F_\alpha(C) \to F_\alpha(D)$. We define $P(f)$ by its action on an element $(x_\alpha) \in P(C)$:

        $`P(f)((x_\alpha)_{\alpha \in I}) = (F_\alpha(f)(x_\alpha))_{\alpha \in I}`$.

        This is well-defined because for each $\alpha$, $F_\alpha(f)(x_\alpha) \in F_\alpha(D)$, so the resulting family is an element of $P(D).

2.  **Show $P$ is a functor**:
    *   **Identity**: For an identity morphism $`\mathrm{id}_C: C \to C`$, we have $`P(\mathrm{id}_C)((x_\alpha)) = (F_\alpha(\mathrm{id}_C)(x_\alpha)) = (\mathrm{id}_{F_\alpha(C)}(x_\alpha)) = (x_\alpha)`$. So $`P(\mathrm{id}_C) = \mathrm{id}_{P(C)}`$.
    *   **Composition**: For morphisms $f: C \to D$ and $g: D \to E$, we have:

        $P(g \circ f)((x_\alpha)) = (F_\alpha(g \circ f)(x_\alpha)) = ((F_\alpha(g) \circ F_\alpha(f))(x_\alpha)) = (F_\alpha(g)(F_\alpha(f)(x_\alpha)))$.

        On the other hand, $(P(g) \circ P(f))((x_\alpha)) = P(g)(P(f)((x_\alpha))) = P(g)((F_\alpha(f)(x_\alpha))) = (F_\alpha(g)(F_\alpha(f)(x_\alpha)))$.

        Thus, $P(g \circ f) = P(g) \circ P(f)$.
    So $P$ is a functor from $\mathcal{C}$ to $\text{Sets}$.

3.  **Define projection natural transformations $\pi_\alpha: P \to F_\alpha$**:
    For each $\alpha \in I$, we define a natural transformation $\pi_\alpha$.
    *   For each object $C \in \mathcal{C}$, define the component map $\pi_\alpha^C: P(C) \to F_\alpha(C)$ to be the canonical projection from the product set, i.e.,

        $`\pi_\alpha^C((x_\beta)_{\beta \in I}) = x_\alpha`$.
    *   **Naturality**: We must show that for any morphism $f: C \to D$, the diagram $F_\alpha(f) \circ \pi_\alpha^C = \pi_\alpha^D \circ P(f)$ commutes.
        Let $(x_\beta) \in P(C)$.

        $`(\pi_\alpha^D \circ P(f))((x_\beta)_{\beta \in I}) = \pi_\alpha^D( (F_\beta(f)(x_\beta))_{\beta \in I} ) = F_\alpha(f)(x_\alpha)`$.

        $(F_\alpha(f) \circ \pi_\alpha^C)((x_\beta)) = F_\alpha(f)(x_\alpha)$.

        The diagram commutes, so each $\pi_\alpha$ is a natural transformation.

4.  **Verify the universal property**:
    Let $G$ be another functor in $\mathrm{Fun}(\mathcal{C}, \text{Sets})$ and let $`\{\psi_\alpha: G \to F_\alpha\}_{\alpha \in I}`$ be a family of natural transformations. We need to show there exists a unique natural transformation $\theta: G \to P$ such that $\pi_\alpha \circ \theta = \psi_\alpha$ for all $\alpha$.
    *   **Construct $\theta$**: For each object $C \in \mathcal{C}$, we have maps $\psi_\alpha^C: G(C) \to F_\alpha(C)$. By the universal property of the product in Sets, there is a unique map $\theta^C: G(C) \to P(C) = \prod_\alpha F_\alpha(C)$ such that for every $\alpha$, $\pi_\alpha^C \circ \theta^C = \psi_\alpha^C$. This map is given by $\theta^C(y) = (\psi_\alpha^C(y))_{\alpha \in I}$ for $y \in G(C)$.
    *   **Show $\theta$ is a natural transformation**: We need to show that for any morphism $f: C \to D$, the diagram $P(f) \circ \theta^C = \theta^D \circ G(f)$ commutes.

        Let $y \in G(C)$.

        $`(P(f) \circ \theta^C)(y) = P(f)((\psi_\alpha^C(y))_\alpha) = (F_\alpha(f)(\psi_\alpha^C(y)))_\alpha`$.

        $(\theta^D \circ G(f))(y) = \theta^D(G(f)(y)) = (\psi_\alpha^D(G(f)(y)))_\alpha$.

        Since each $\psi_\alpha$ is a natural transformation, we have $\psi_\alpha^D \circ G(f) = F_\alpha(f) \circ \psi_\alpha^C$.

        Therefore, $`(F_\alpha(f)(\psi_\alpha^C(y)))_\alpha = (\psi_\alpha^D(G(f)(y)))_\alpha`$.
        
        This shows that $P(f) \circ \theta^C = \theta^D \circ G(f)$, so $\theta$ is a natural transformation.
    *   **Uniqueness of $\theta$**: Suppose $\theta': G \to P$ is another natural transformation such that $\pi_\alpha \circ \theta' = \psi_\alpha$ for all $\alpha$. For any object $C$, this means $\pi_\alpha^C \circ \theta'^C = \psi_\alpha^C$. By the uniqueness part of the universal property of the product in Sets, $\theta'^C$ must be equal to $\theta^C$. Since this holds for all $C$, $\theta' = \theta$.

This completes the proof.
