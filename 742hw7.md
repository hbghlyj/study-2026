# Problem 6.20
Let $R$ be a ring, $M$ a module. Define the map

$D(M): M \rightarrow \operatorname{Hom}(\operatorname{Hom}(M, R), R) \quad \text { by } \quad(D(M)(m))(\alpha):=\alpha(m) .$


If $D(M)$ is an isomorphism, call $M$ reflexive. Show:

(1) $D: \mathrm{Id}_{R\text{-mod}} \rightarrow \operatorname{Hom}(\operatorname{Hom}(\bullet, R), R)$ is a natural transformation.

(2) Let $M_i$ for $1 \leq i \leq n$ be modules. Then $D\left(\bigoplus_{i=1}^n M_i\right) \cong \bigoplus_{i=1}^n D\left(M_i\right)$.

(3) Assume $M$ is finitely generated and projective. Then $M$ is reflexive.

# Problem 8.34

Let $X$ be a variable, $\omega$ a complex cube root of 1, and $\sqrt[3]{2}$ the real cube root of 2.
Set $k:=\mathbb{Q}(\omega)$ and $K:=k[\sqrt[3]{2}]$. Show $K \cong k[X] /\left\langle X^3-2\right\rangle$ and then $K \otimes_k K \cong K \times K \times K$.

**Proof.**

First, we show that $K \cong k[X] /\left\langle X^3-2\right\rangle$. Consider the evaluation map $\phi: k[X] \rightarrow K$ defined by $\phi(f(X)) = f(\sqrt[3]{2})$. This is a surjective ring homomorphism. The kernel of $\phi$ is generated by the minimal polynomial of $\sqrt[3]{2}$ over $k$. We have $[k:\mathbb{Q}] = [\mathbb{Q}(\omega):\mathbb{Q}] = 2$ and $[\mathbb{Q}(\sqrt[3]{2}):\mathbb{Q}]=3$. Since $\gcd(2,3)=1$, the degree of the extension $K/k$ is $[K:k] = [\mathbb{Q}(\omega, \sqrt[3]{2}):\mathbb{Q}(\omega)]=3$. Thus, the minimal polynomial of $\sqrt[3]{2}$ over $k$ must have degree 3. The polynomial $X^3-2$ is monic, has degree 3, and has $\sqrt[3]{2}$ as a root, so it must be the minimal polynomial. Therefore, $\ker(\phi) = \langle X^3-2 \rangle$. By the First Isomorphism Theorem, we have $K \cong k[X] /\left\langle X^3-2\right\rangle$.

Now, we show that $K \otimes_k K \cong K \times K \times K$. Since $K \cong k[X] /\left\langle X^3-2\right\rangle$, we can write $K \otimes_k K \cong (k[X] /\left\langle X^3-2\right\rangle) \otimes_k (k[X] /\left\langle X^3-2\right\rangle)$.

In the following problems, $R$ is a domain. Consider the following definition:

>Let $M$ be an $R$-module. An element $m \in M$ is said to be torsion if there exists $`r \in R-\{0\}`$ such that $r m=0$. A module $M$ is torsion if all $m \in M$ are torsion. We say that $M$ is torsion-free if the only torsion element $m \in M$ is $m=0$.

# Problem A
Show that both classes of modules (torsion and torsion-free) are stable under extension: if in a short exact sequence

$0 \rightarrow L \rightarrow M \rightarrow N \rightarrow 0$

the modules $L$ and $N$ belong to the class, then so does $M$.
# Problem B
Show that a projective module is torsion-free.

**Proof.** Let $P$ be a projective module and suppose $m \in P$ is a torsion element. Then there exists $`r \in R-\{0\}`$ such that $r m=0$. Since $P$ is projective, there exists a module $Q$ such that $P \oplus Q$ is free. Let $\{e_i\}$ be a basis for $P \oplus Q$. We can write $m$ as a linear combination of the basis elements: $m = \sum a_i e_i$. Then we have

$$
r m = r \sum a_i e_i = \sum r a_i e_i = 0.
$$

Since $`\{e_i\}`$ is a basis, the only way for this to hold is if $r a_i = 0$ for all $i$. But since $R$ is a domain and $r \neq 0$, this implies that $a_i = 0$ for all $i$. Therefore, $m = 0$, and we conclude that $P$ is torsion-free.

# Problem C
Show that if $M$ and $N$ are torsion, then so is $M \otimes_R N$.

**Proof.** Let $M$ and $N$ be torsion modules. Then for every $m \in M$, there exists a nonzero $r_m \in R$ such that $r_m m = 0$. Similarly, for every $n \in N$, there exists a nonzero $s_n \in R$ such that $s_n n = 0$. Consider an element $x \in M \otimes_R N$. We can write $x$ as a finite sum of pure tensors: $x = \sum m_i \otimes n_i$. For each $m_i$, there exists a nonzero $r_{m_i} \in R$ such that $r_{m_i} m_i = 0$. For each $n_i$, there exists a nonzero $s_{n_i} \in R$ such that $s_n n_i = 0$. Let $r = \prod_{i} r_{m_i}$. Since $R$ is a domain, $r \neq 0$. Then $r x = r \sum m_i \otimes n_i = \sum (r m_i) \otimes n_i$. For each $i$, $r_{m_i}$ is a factor of $r$, so $r m_i = 0$. Thus, $r x = \sum 0 \otimes n_i = 0$. Since the product of nonzero elements in a domain is nonzero, we conclude that $x$ is a torsion element. Thus, $M \otimes_R N$ is a torsion module.
