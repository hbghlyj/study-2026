# Problem 6.20
Let $R$ be a ring, $M$ a module. Define the map

$D(M): M \rightarrow \operatorname{Hom}(\operatorname{Hom}(M, R), R) \quad \text { by } \quad(D(M)(m))(\alpha):=\alpha(m) .$


If $D(M)$ is an isomorphism, call $M$ reflexive. Show:

(1) $D: \mathrm{Id}_{R\text{-mod}} \rightarrow \operatorname{Hom}(\operatorname{Hom}(\bullet, R), R)$ is a natural transformation.

(2) Let $M_i$ for $1 \leq i \leq n$ be modules. Then $D\left(\bigoplus_{i=1}^n M_i\right) \cong \bigoplus_{i=1}^n D\left(M_i\right)$.

(3) Assume $M$ is finitely generated and projective. Then $M$ is reflexive.

# Problem 8.34

Let $X$ be a variable, $\omega$ a complex cube root of 1, and $\sqrt[3]{2}$ the real cube root of 2.
Set $k:=\mathbb{Q}(\omega)$ and $K:=k[\sqrt[3]{2}]$. Show $K \cong k[X] /\left\langle X^3-2\right\rangle$ and then $K \otimes_k K \cong K \times K \times K$.

In the following problems, $R$ is a domain. Consider the following definition:
Let $M$ be an $R$-module. An element $m \in M$ is said to be torsion if there exists $r \in R-\{0\}$ such that $r m=0$. A module $M$ is torsion if all $m \in M$ are torsion. We say that $M$ is torsion-free if the only torsion element $m \in M$ is $m=0$.

# Problem A
Show that both classes of modules (torsion and torsion-free) are stable under extension: if in a short exact sequence

$0 \rightarrow L \rightarrow M \rightarrow N \rightarrow 0$

the modules $L$ and $N$ belong to the class, then so does $M$.
# Problem B
Show that a projective module is torsion-free.
# Problem C
Show that if $M$ and $N$ are torsion, then so is $M \otimes_R N$.
# Problem D
By contrast, show that if $M$ and $N$ are torsion-free, $M \otimes_R N$ need not be torsion free, by considering the following example: $R=\mathbb{Q}[x, y], M = N = (x, y)$.
