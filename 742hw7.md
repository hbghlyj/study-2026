# Problem 6.20
Let $R$ be a ring, $M$ a module. Define the map

$D(M): M \rightarrow \operatorname{Hom}(\operatorname{Hom}(M, R), R) \quad \text { by } \quad(D(M)(m))(\alpha):=\alpha(m) .$


If $D(M)$ is an isomorphism, call $M$ reflexive. Show:

(1) $D: \mathrm{Id}_{R\text{-mod}} \rightarrow \operatorname{Hom}(\operatorname{Hom}(\bullet, R), R)$ is a natural transformation.

**Proof.** We need to show that for any morphism $f: M \rightarrow N$ in $R$-mod, the following diagram commutes:

$$
\begin{CD}
M @>D(M)>> \operatorname{Hom}(\operatorname{Hom}(M, R), R) \\
@VfVV @VV{\operatorname{Hom}(\operatorname{Hom}(f, R), R)}V \\
N @>D(N)>> \operatorname{Hom}(\operatorname{Hom}(N, R), R)
\end{CD}
$$

Take any $m \in M$ and $\alpha \in \operatorname{Hom}(N, R)$. We need to show that

$$
(\operatorname{Hom}(\operatorname{Hom}(f, R), R)(D(M)(m)))(\alpha) = (D(N)(f(m)))(\alpha).
$$

By definition, we have

\begin{align*}
(\operatorname{Hom}(\operatorname{Hom}(f, R), R)(D(M)(m)))(\alpha) &= (D(M)(m))(\operatorname{Hom}(f, R)(\alpha)) \\
&= (D(M)(m))(\alpha \circ f) \\
&= (\alpha \circ f)(m) \\
&= \alpha(f(m)) \\
&= (D(N)(f(m)))(\alpha)
\end{align*}

Thus, the diagram commutes and $D$ is a natural transformation.

(2) Let $M_i$ for $1 \leq i \leq n$ be modules. Then $D\left(\bigoplus_{i=1}^n M_i\right) \cong \bigoplus_{i=1}^n D\left(M_i\right)$.

(3) Assume $M$ is finitely generated and projective. Then $M$ is reflexive.

# Problem 8.34

Let $X$ be a variable, $\omega$ a complex cube root of 1, and $\sqrt[3]{2}$ the real cube root of 2.
Set $k:=\mathbb{Q}(\omega)$ and $K:=k[\sqrt[3]{2}]$. Show $K \cong k[X] /\left\langle X^3-2\right\rangle$ and then $K \otimes_k K \cong K \times K \times K$.

**Proof.**

First, we show that $K \cong k[X] /\left\langle X^3-2\right\rangle$. Consider the evaluation map $\phi: k[X] \rightarrow K$ defined by $\phi(f(X)) = f(\sqrt[3]{2})$. This is a surjective ring homomorphism. The kernel of $\phi$ is generated by the minimal polynomial of $\sqrt[3]{2}$ over $k$. We have $[k:\mathbb{Q}] = [\mathbb{Q}(\omega):\mathbb{Q}] = 2$ and $[\mathbb{Q}(\sqrt[3]{2}):\mathbb{Q}]=3$. Since $\gcd(2,3)=1$, the degree of the extension $K/k$ is $[K:k] = [\mathbb{Q}(\omega, \sqrt[3]{2}):\mathbb{Q}(\omega)]=3$. Thus, the minimal polynomial of $\sqrt[3]{2}$ over $k$ must have degree 3. The polynomial $X^3-2$ is monic, has degree 3, and has $\sqrt[3]{2}$ as a root, so it must be the minimal polynomial. Therefore, $\ker(\phi) = \langle X^3-2 \rangle$. By the First Isomorphism Theorem, we have $K \cong k[X] /\left\langle X^3-2\right\rangle$.

Now, we show that $K \otimes_k K \cong K \times K \times K$. Since $K \cong k[X] /\left\langle X^3-2\right\rangle$, we can write $K \otimes_k K \cong (k[X] /\left\langle X^3-2\right\rangle) \otimes_k (k[X] /\left\langle X^3-2\right\rangle)$.

In the following problems, $R$ is a domain. Consider the following definition:

>Let $M$ be an $R$-module. An element $m \in M$ is said to be torsion if there exists $`r \in R-\{0\}`$ such that $r m=0$. A module $M$ is torsion if all $m \in M$ are torsion. We say that $M$ is torsion-free if the only torsion element $m \in M$ is $m=0$.

# Problem A
Show that both classes of modules (torsion and torsion-free) are stable under extension: if in a short exact sequence

$0 \rightarrow L \rightarrow M \rightarrow N \rightarrow 0$

the modules $L$ and $N$ belong to the class, then so does $M$.

**Proof.**

Consider the short exact sequence $0 \rightarrow L \rightarrow M \rightarrow N \rightarrow 0$.

First, assume that $L$ and $N$ are torsion modules. Let $m \in M$. Let $f: M \rightarrow N$ be the map from the sequence. The image $f(m)$ is in the torsion module $N$, so there exists a nonzero $r \in R$ such that $r f(m) = 0$. By linearity, $f(r m) = 0$, so $r m$ is in $\ker(f)$. By exactness, $\ker(f)$ is the image of the map from $L$, so we can identify $r m$ with an element in $L$. Since $L$ is a torsion module, there exists a nonzero $s \in R$ such that $s(r m) = 0$. Then $(sr)m = 0$. As $R$ is a domain, $sr \neq 0$, so $m$ is a torsion element. Thus, $M$ is a torsion module.

Second, assume that $L$ and $N$ are torsion-free. Let $m \in M$ be a torsion element, so there exists a nonzero $r \in R$ with $r m = 0$. Applying $f$, we get $f(r m) = r f(m) = 0$. Since $N$ is torsion-free and $r \neq 0$, we must have $f(m) = 0$. This means $m \in \ker(f)$, so $m$ is in the image of $L$. Since the map from $L$ is injective, we can view $m$ as an element of $L$. But $L$ is torsion-free and $m$ is a torsion element, so $m=0$. Thus, $M$ is torsion-free.

# Problem B
Show that a projective module is torsion-free.

**Proof.** Let $P$ be a projective module and suppose $m \in P$ is a torsion element. Then there exists $`r \in R-\{0\}`$ such that $r m=0$. Since $P$ is projective, there exists a module $Q$ such that $P \oplus Q$ is free. Let $\{e_i\}$ be a basis for $P \oplus Q$. We can write $(m,0)$ as a linear combination of the basis elements: $(m,0) = \sum a_i e_i$. Then we have

$$
r(m,0) = r \sum a_i e_i = \sum r a_i e_i = 0.
$$

Since $`\{e_i\}`$ is a basis, the only way for this to hold is if $r a_i = 0$ for all $i$. But since $R$ is a domain and $r \neq 0$, this implies that $a_i = 0$ for all $i$. Therefore, $m = 0$, and we conclude that $P$ is torsion-free.

# Problem C
Show that if $M$ and $N$ are torsion, then so is $M \otimes_R N$.

**Proof.** 

Note the stronger result: if $M$ is a torsion module, then $M\otimes_{R}N$ is a torsion module for any $R$-module $N$.

Consider an element $x \in M \otimes_R N$. We can write $x$ as a finite sum of pure tensors: $x = \sum m_i \otimes n_i$.

Since $M$ is a torsion module, for each $m_i$, there exists a nonzero $r_i \in R$ such that $r_i m_i = 0$.

Let $r = \prod_{i} r_i$. Since $R$ is a domain and each $r_i \neq 0$, we have $r \neq 0$. Then $r x = r \sum m_i \otimes n_i = \sum (r m_i) \otimes n_i$.

For each $i$, $r_i$ is a factor of $r$, so $r m_i = 0$. Thus, $r x = \sum 0 \otimes n_i = 0$.

Since for an arbitrary $x \in M \otimes_R N$ we found a nonzero $r \in R$ such that $rx=0$, we conclude that $x$ is a torsion element. Thus, $M \otimes_R N$ is a torsion module.

# Problem D
By contrast, show that if $M$ and $N$ are torsion-free, $M \otimes_R N$ need not be torsion free, by considering the following example: $R=\mathbb{Q}[x, y], M = N = (x, y)$.

**Proof.**

Consider $x \otimes y - y \otimes x \in M \otimes_R N$. We will show that this element is a torsion element, even though $M$ and $N$ are torsion-free.

Let $r=x \in R$. Then consider $r(x \otimes y - y \otimes x)$:

$$
x(x \otimes y - y \otimes x) = x^2 \otimes y - xy \otimes x
$$

To show that $x^2 \otimes y - xy \otimes x = 0$, or equivalently $x^2 \otimes y = xy \otimes x$, we use the R-bilinearity of the tensor product. Specifically, for any $r' \in R$, $m \in M$, and $n \in N$, we have $r'm \otimes n = m \otimes r'n$.

Applying this property:
1. For $x^2 \otimes y$: We can write $x^2 \otimes y = (x \cdot x) \otimes y$. Using the property with $r'=x$, $m=x$, $n=y$, we get $x^2 \otimes y = x \otimes (x \cdot y) = x \otimes xy$.
2. For $xy \otimes x$: We can write $xy \otimes x = (y \cdot x) \otimes x$. Using the property with $r'=y$, $m=x$, $n=x$, we get $xy \otimes x = x \otimes (y \cdot x) = x \otimes yx$.

Since $R=\mathbb{Q}[x,y]$ is commutative, $xy = yx$. Therefore, $x \otimes xy = x \otimes yx$.

Thus, $x^2 \otimes y = x \otimes xy = x \otimes yx = xy \otimes x$.

Therefore, $x^2 \otimes y - xy \otimes x = 0$.

Since $x \in R$ is non-zero and $x(x \otimes y - y \otimes x) = 0$, the element $x \otimes y - y \otimes x$ is a torsion element.

To show that $x \otimes y - y \otimes x$ is nonzero, we need to construct a homomorphism $f: M \otimes_R N \rightarrow A$ for some $R$-module $A$ such that $f(x \otimes y - y \otimes x) \neq 0$.

Take $A = \Lambda^2(M)$, the second exterior power of $M$. This is defined as the quotient of the tensor product $M \otimes_R M$ by the submodule generated by elements of the form $m \otimes m$ for $m \in M$.

Define $f: M \otimes_R N \rightarrow \Lambda^2(M)$ by $f(m \otimes n) = m \wedge n$, where $m \wedge n$ is the image of $m \otimes n$ in $\Lambda^2(M)$.

We can compute $f(x \otimes y - y \otimes x)$:

$$
f(x \otimes y - y \otimes x) = f(x \otimes y) - f(y \otimes x) = x \wedge y - y \wedge x = 2(x \wedge y).
$$

Since $x \wedge y$ is nonzero in $\Lambda^2(M)$ (as $\Lambda^2(M) \cong R/(x,y) \cong \mathbb{Q}$), we have $f(x \otimes y - y \otimes x) = 2(x \wedge y) \neq 0$.

Therefore, $x \otimes y - y \otimes x$ is a nonzero torsion element in $M \otimes_R N$, showing that $M \otimes_R N$ is not torsion-free.
